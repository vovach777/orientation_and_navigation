Ориентация, навигация и мышление

1. Базовая идея

Мышление можно рассматривать как работу агента, который решает текущую задачу внутри внутренней модели мира.

Для этого необходимы:

[
\boxed{
Belief + Progress + Experience
}
]

где:

* Belief — убеждения: как устроен мир, какие в нём есть объекты, агенты, законы и возможные переходы;
* Progress — прогресс: где находится решение текущей задачи;
* Experience — опыт: что произошло и какие новые данные получила система.

Опыт обновляет одновременно и убеждения, и прогресс:

[
\boxed{
(B_t,P_t)+E_t
\rightarrow
(B_{t+1},P_{t+1})
}
]

⸻

2. Карта

Убеждения позволяют построить внутреннюю карту:

[
M=M(B)
]

Карта необязательно является физическим пространством.

Это может быть:

* физическая среда;
* план;
* алгоритм;
* доказательство;
* социальная ситуация;
* техническая проблема;
* научная теория;
* пространство возможных гипотез.

Минимально карта содержит:

[
M=(S,T)
]

где:

* (S) — состояния;
* (T) — возможные переходы между ними.

⸻

3. Агент

На карте существуют не только пассивные объекты.

Система способна помещать туда агентов — автономные модели объектов, которым приписываются:

[
A_i=(Body_i,Sensors_i,B_i,G_i,D_i)
]

где:

* (Body_i) — тело и возможности действия;
* (Sensors_i) — доступные агенту каналы опыта;
* (B_i) — его предполагаемые убеждения;
* (G_i) — его цели;
* (D_i) — модель принятия решений.

Агент отличается от пассивного объекта тем, что его дальнейшее состояние определяется не только внешними воздействиями, но и собственной внутренней моделью поведения.

⸻

4. Оркестратор

У человека существует особый агент — оркестратор.

Оркестратор является владельцем реального тела и единственным внутренним агентом, решения которого непосредственно связаны с исполнительным контуром организма:

[
O_{\text{virtual}}
\rightarrow
Decision
\rightarrow
Body_{\text{real}}
\rightarrow
Action
\rightarrow
World
]

Остальные внутренние агенты существуют только как симулируемые модели.

Поэтому:

[
\boxed{
Orchestrator \subset Agent
}
]

но оркестратор отличается связью с реальным телом.

⸻

5. Я и тело

Я и тело в этой модели не следует разделять.

[
\boxed{
Я = воплощённый агент
}
]

Тело определяет:

* какие действия доступны;
* какие состояния достижимы;
* какие сигналы можно получить;
* где проходит граница между агентом и средой.

Сенсоры определяют интерфейс опыта:

[
World
\rightarrow
Sensors
\rightarrow
Experience
]

а тело и моторика — интерфейс воздействия:

[
Agent
\rightarrow
Action
\rightarrow
World
]

Поэтому тело является границей между Я и картой.

⸻

6. Ориентация

Ориентация отвечает на вопрос:

[
\boxed{
\text{Где я сейчас?}
}
]

Но «где» необязательно означает физические координаты.

В задаче это может быть:

* какой этап плана достигнут;
* какая гипотеза сейчас проверяется;
* где находится расследование ошибки;
* какая часть доказательства уже построена;
* какое состояние взаимодействия достигнуто.

Ориентацию можно определить как поиск такого положения на карте, которое лучше всего согласует текущий опыт с убеждениями:

[
\boxed{
P_t=
\arg\max_P
Compatibility(B_t,E_t,M,P)
}
]

То есть:

[
Beliefs+Experience
\rightarrow
Orientation
\rightarrow
Progress
]

Ориентация фактически определяет текущий прогресс задачи.

⸻

7. Навигация

После ответа:

Где я?

возникает вопрос:

Куда двигаться дальше?

Навигация ищет переход из текущего состояния к цели:

[
P_t
\rightarrow
P_{t+1}
\rightarrow
\dots
\rightarrow
G
]

То есть:

[
\boxed{
Navigation(B,M,P_t,G)
\rightarrow
NextStep
}
]

Ориентация ищет настоящее.

Навигация ищет будущее.

[
\boxed{
\begin{aligned}
Orientation &: Experience \rightarrow CurrentState\
Navigation &: CurrentState+Goal \rightarrow Trajectory
\end{aligned}
}
]

⸻

8. Прогресс

Progress — это текущее положение решения задачи на карте.

Например:

получить данные       ✓
        ↓
построить модель      ✓
        ↓
проверить гипотезу   ← Progress
        ↓
исправить модель
        ↓
получить результат   ← Goal

Прогресс существует относительно конкретной задачи:

[
P=P(Q,M)
]

Поэтому одна и та же система одновременно может иметь разные прогрессы в разных картах.

⸻

9. Опыт

Опыт — это информация, полученная после взаимодействия агента с реальным или виртуальным миром.

Есть два вида опыта:

[
\boxed{
E=
{E_R,E_V}
}
]

где:

* (E_R) — реальный опыт;
* (E_V) — виртуальный опыт.

Реальный опыт возникает:

[
Agent
\rightarrow
Action
\rightarrow
World
\rightarrow
E_R
]

Виртуальный:

[
Agent_V
\rightarrow
Action_V
\rightarrow
WorldModel
\rightarrow
E_V
]

Оба способны изменять убеждения.

Но реальный опыт имеет особый статус: он проверяет внутреннюю модель реальностью.

⸻

10. Убеждения

Убеждение — это не обязательно словесное утверждение.

Это любое устойчивое внутреннее состояние, которое изменяет будущий inference.

Функционально:

[
\boxed{
Belief =
\text{то, что изменяет последующую интерпретацию опыта и выбор переходов}
}
]

Убеждения формируют карту:

[
B\rightarrow M
]

Опыт изменяет убеждения:

[
B_t+E_t\rightarrow B_{t+1}
]

Поэтому:

[
\boxed{
Experience
\rightarrow
Belief
\rightarrow
Future inference
}
]

⸻

11. Реальный и виртуальный опыт

Симуляция способна создать новый виртуальный опыт:

[
(B_t,P_t)
\rightarrow
Simulation
\rightarrow
E_V
]

который сразу изменяет систему:

[
(B_t,P_t)+E_V
\rightarrow
(B_{t+1},P_{t+1})
]

Поэтому агент способен обучаться ещё до реального действия.

Возникают новые убеждения:

[
B_0
\rightarrow
E_{V1}
\rightarrow
B_1
\rightarrow
E_{V2}
\rightarrow
B_2
\rightarrow\dots
]

Так возможно многошаговое мышление без непосредственного взаимодействия с реальным миром.

⸻

12. Реальность как проверка

Виртуальный опыт полностью зависит от текущих убеждений.

Поэтому он может быть ошибочным.

Из модели возникает прогноз:

[
\hat E_R
]

после действия приходит реальный опыт:

[
E_R
]

и вычисляется ошибка:

[
\Delta=E_R-\hat E_R
]

Она изменяет убеждения:

[
B_{t+1}=Update(B_t,\Delta)
]

Если виртуальный опыт совпал с реальным:

[
E_V\approx E_R
]

убеждение получает практическое подтверждение.

Если нет:

[
E_V\neq E_R
]

модель должна быть исправлена.

Таким образом:

[
\boxed{
Simulation
\rightarrow
VirtualExperience
\rightarrow
Belief
\rightarrow
Prediction
\rightarrow
RealExperience
\rightarrow
Correction
}
]

⸻

13. Мысленный эксперимент

Мысленный эксперимент — это запуск агента внутри виртуальной карты.

Оркестратор:

1. строит виртуальный мир;
2. создаёт экземпляр агента;
3. задаёт его тело;
4. задаёт сенсоры;
5. задаёт убеждения и цели;
6. помещает его в определённую точку;
7. запускает ориентацию и навигацию;
8. получает виртуальный опыт.

Формально:

[
A_V=
Instantiate(A,\theta,S_0)
]

и затем:

[
A_V
\leftrightarrow
World_V
]

через цикл:

[
Action_V
\rightarrow
World_V
\rightarrow
Experience_V
\rightarrow
Inference
\rightarrow
Action_V’
]

Поэтому мысленный эксперимент — не просто представление сцены.

[
\boxed{
\text{Мысленный эксперимент}

\text{временное подключение агента к виртуальному миру вместо реального}
}
]

⸻

14. Клонирование агентов

Оркестратор способен создать несколько экземпляров одного агента:

[
A_1=A(\theta_1)
]

[
A_2=A(\theta_2)
]

[
A_3=A(\theta_3)
]

и запустить их в разных условиях.

Например:

               MODEL A
                  │
       ┌──────────┼──────────┐
       ▼          ▼          ▼
    Agent 1    Agent 2    Agent 3
    params X   params Y   params Z
       │          │          │
       ▼          ▼          ▼
   simulation simulation simulation
       └──────────┼──────────┘
                  ▼
              comparison

Если различные симуляции дают устойчивый результат, возникает новое убеждение или гипотеза.

⸻

15. Другие агенты

Оркестратор способен моделировать не только себя.

Он может создать автономную модель другого человека:

[
A_{other}

(
Body,
Sensors,
Beliefs,
Goals,
DecisionModel
)
]

и спросить:

Если этот агент оказался здесь и обладает такими убеждениями и целями, куда он будет двигаться?

Тогда используется тот же механизм:

[
(B_A,P_A,E_A)
\rightarrow
Orientation
\rightarrow
Navigation
\rightarrow
E_A’
]

Оркестратор получает результат как виртуальный опыт:

[
E_A^{virtual}
\rightarrow
B_O’
]

Так появляется прогноз поведения других.

⸻

16. Рекурсивное моделирование

Возможна рекурсия:

[
O
\supset
A
\supset
Model_A(O)
]

Например:

Я думаю, что он думает, что я поступлю X.

То есть один агент может содержать модель другого агента, который содержит модель первого.

Глубина такой рекурсии ограничивается вычислительными ресурсами.

⸻

17. Навигация в убеждениях

До движения по прогрессу система должна выбрать релевантную структуру убеждений.

Поэтому возникает первый уровень навигации:

[
B_t
\rightarrow
B_Q
]

где (B_Q) — убеждения, необходимые для текущей задачи.

Это можно назвать:

[
\boxed{
Navigation_{belief}
}
]

Система ищет:

Какая модель лучше объясняет происходящее?

⸻

18. Навигация в прогрессе

После выбора рабочей карты начинается второй уровень:

[
P_t
\rightarrow
P_{t+1}
\rightarrow
\dots
\rightarrow
G
]

Это:

[
\boxed{
Navigation_{progress}
}
]

Поэтому минимальный цикл:

[
\boxed{
Navigation_{belief}
\rightarrow
Navigation_{progress}
\rightarrow
Experience
\rightarrow
Update(B,P)
}
]

⸻

19. Пример: пробуждение в больнице

Человек потерял сознание в одном месте и проснулся ночью в больнице.

Последняя известная карта говорит:

[
M_1=\text{предыдущая ситуация}
]

Но новый опыт:

[
E=
{
\text{незнакомая кровать},
\text{темнота},
\text{звуки приборов},
\dots
}
]

не позволяет найти согласованное положение:

[
E\not\approx Prediction(M_1,P)
]

Ориентация терпит неудачу.

Система перебирает гипотезы:

[
H_1=\text{дом}
]

[
H_2=\text{гостиница}
]

[
H_3=\text{больница}
]

Гипотеза (H_3) создаёт карту:

[
M(H_3)
]

в которой текущий опыт становится объяснимым:

[
E\approx Prediction(M(H_3),P’)
]

Возникает субъективный момент:

«А. Я в больнице.»

Это момент успешной новой ориентации.

⸻

20. Когда текущая карта не работает

Иногда проблема не в положении внутри карты.

Проблема в самой карте.

Есть:

[
M_1,\quad P_t,\quad G
]

но:

[
P_t\not\rightarrow G
]

или опыт систематически противоречит модели:

[
E_t\neq Prediction(M_1,P_t)
]

Тогда продолжать навигацию внутри (M_1) бессмысленно.

Необходимо преобразование:

[
\boxed{
M_1\rightarrow M_2
}
]

После этого выполняется новая ориентация:

[
E_t+B_t
\rightarrow
P_t’
\in M_2
]

и новая навигация:

[
P_t’\rightarrow G
]

⸻

21. Пространство гипотез

Каждая карта может быть следствием некоторой гипотезы:

[
H_i\rightarrow M_i
]

Следовательно, агент способен двигаться не только внутри карты, но и по пространству гипотез:

[
H_1
\rightarrow
H_2
\rightarrow
H_3
\rightarrow\dots
]

Получаются два уровня движения:

[
\boxed{
\begin{aligned}
P_t &\rightarrow P_{t+1} && \text{движение внутри карты}\
H_i &\rightarrow H_j && \text{движение между картами}
\end{aligned}
}
]

⸻

22. Прыжок

Иногда внутри текущей гипотезы дальнейший путь к цели отсутствует:

[
P_t\not\rightarrow G
]

Тогда требуется не следующий шаг внутри модели, а переход к новой гипотезе:

[
\boxed{
H_i\rightarrow H_j
}
]

После чего:

[
H_j\rightarrow M_j
]

и:

[
Orientation(M_j)
\rightarrow
Navigation(M_j)
]

Такой переход можно назвать прыжком.

Он не является обычной дедукцией внутри прежней карты.

Это:

[
\boxed{
Jump=
\text{переход в пространстве гипотез,
меняющий карту решения}
}
]

⸻

23. Метанавигация

Таким образом существуют минимум три уровня:

[
\boxed{
\begin{aligned}
Orientation &: \text{где я на карте}\
Navigation &: \text{как двигаться к цели}\
MetaNavigation &: \text{какую карту использовать}
\end{aligned}
}
]

Когда обычная навигация не приводит к цели, система может начать навигировать уже по пространству карт.

⸻

24. Эйнштейновская схема

Схема Эйнштейна:

[
E\dashrightarrow A\rightarrow S\rightarrow E
]

естественно интерпретируется в этой архитектуре.

Эмпирический опыт:

[
E_R
]

требует построения или выбора гипотезы:

[
E_R
\rightarrow
H
]

гипотеза определяет карту:

[
H\rightarrow M
]

внутри неё начинается навигация:

[
M
\rightarrow
S_1,S_2,S_3,\dots
]

Следствия создают виртуальный опыт и реальные прогнозы:

[
S\rightarrow E_V
]

которые затем проверяются:

[
E_V
\stackrel{?}{\approx}
E_R’
]

Если старая система убеждений не позволяет двигаться дальше, происходит:

[
H_i\rightarrow H_j
]

— переход к новой гипотезе и новой карте.

В этом смысле эйнштейновский интуитивный «прыжок» можно трактовать как метанавигационный переход после неудачи ориентации или навигации в прежней модели.

⸻

25. Инференс

Инференс в этой концепции — не обязательно отдельный логический алгоритм.

Функционально это процесс:

[
\boxed{
(B_t,P_t,E_t)
\rightarrow
(B_{t+1},P_{t+1})
}
]

То есть система:

1. интерпретирует опыт;
2. ориентируется;
3. выбирает следующий переход;
4. обновляет прогресс;
5. при необходимости обновляет убеждения.

Для рекуррентной нервной системы это может быть непрерывная динамика:

[
h_{t+1}=F(h_t,E_t;\theta_t)
]

где:

* быстро меняющееся (h_t) функционально соответствует прогрессу;
* более медленные параметры (\theta_t) — убеждениям;
* вход (E_t) — опыту.

⸻

26. Биологическая реализация

У простого организма:

[
World
\rightarrow
Experience
\rightarrow
NetworkState
\rightarrow
Action
\rightarrow
World
]

Текущий state сети несёт историю предыдущих состояний.

Опыт:

[
E_t
]

быстро изменяет текущую динамику:

[
P_t\rightarrow P_{t+1}
]

и медленнее может изменять саму систему:

[
B_t\rightarrow B_{t+1}
]

То есть:

[
\boxed{
Experience
\begin{cases}
\text{быстро изменяет Progress}\
\text{медленно изменяет Beliefs}
\end{cases}
}
]

⸻

27. Возможный переход к мышлению

Примитивный агент получает только реальный опыт:

[
World
\rightarrow
E_R
\rightarrow
(B,P)
]

Более сложный агент способен временно заменить реальность моделью:

[
(B,P)
\rightarrow
WorldModel
\rightarrow
E_V
\rightarrow
(B’,P’)
]

и повторять это:

[
(B_0,P_0)
\rightarrow
E_{V1}
\rightarrow
(B_1,P_1)
\rightarrow
E_{V2}
\rightarrow
(B_2,P_2)
\rightarrow\dots
]

Таким образом он способен двигаться вперёд внутри модели без реального действия.

Это даёт минимальное определение мышления:

[
\boxed{
\textbf{Мышление — способность продолжать inference,
используя виртуально сгенерированный опыт вместо непосредственного реального опыта.}
}
]

⸻

28. Абстракция и перенос

Результаты одной симуляции могут породить убеждение:

[
Simulation
\rightarrow
E_V
\rightarrow
H
]

которое затем переносится на другую карту:

31. Итоговая формулировка

Мыслящая система поддерживает убеждения о мире, строит из них карты текущих задач и размещает в этих картах воплощённых агентов. Главным агентом является оркестратор — Я вместе с телом, связанное с реальным исполнительным контуром.

Ориентация определяет текущее положение прогресса на карте по доступному опыту и убеждениям. Навигация ищет дальнейший путь к цели. Действие создаёт реальный опыт, а симуляция — виртуальный. Оба вида опыта изменяют убеждения и прогресс, однако реальный опыт служит окончательной проверкой виртуальных построений.

Оркестратор способен создавать экземпляры других агентов, задавать им тело, сенсоры, убеждения, цели и начальные условия, запускать их внутри виртуальных карт и получать из их поведения виртуальный опыт. Из результатов симуляций возникают новые убеждения, гипотезы и абстракции, которые могут переноситься на другие карты и других агентов.

Когда движение внутри текущей карты перестаёт объяснять опыт или больше не позволяет приблизиться к цели, система начинает навигацию по пространству гипотез. Переход к новой гипотезе преобразует саму карту. После этого выполняются новая ориентация и новая навигация. Такой переход является метанавигационным прыжком.

В предельно короткой форме:

[
\boxed{
\textbf{Опыт определяет, где мы.
Навигация определяет, куда идти.
Убеждения определяют карту.
Мышление позволяет пройти этот путь виртуально.
А если путь невозможен — изменить саму карту.}
}
]
